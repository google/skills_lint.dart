# Skills shipped with skills_lint

The skills in this directory are shipped with the `skills_lint` package.
They are intended for users of the package to help them use it effectively.

To install these skills into your project's `.agents/skills/` directory, run
this command with the [skills](https://pub.dev/packages/skills) package from
the root of a Dart package that depends on `skills_lint`:

```bash
dart run skills@^1.0.0 get --agent generic --package skills_lint --all
```
