# Reply templates

Change the details to fit the issue. Keep the tone friendly and short.

## Asking for details

> Thanks for the report. I couldn't reproduce this yet. Could you share:
>
> - the output of `skills_lint --version`,
> - the exact command you ran, and the directory you ran it from,
> - a `SKILL.md` that shows the problem, if you can share one?
>
> I've added `needs-info`. If we don't hear back in 30 days, we'll close
> this, and you can reopen it at any time.

## Closing a duplicate

> Thanks for the report. This is the same problem as #NNN, so I'm closing
> this one to keep the discussion in one place. Please add any new details
> there.

## Closing after no reply

> Closing this because we haven't heard back in 30 days. If you still see
> the problem, reopen the issue with the details asked for above.
