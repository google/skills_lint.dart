# Sample skills: benchmark test data

The folders here are test data for the benchmark fixture. The fixture copies
them, with numbered names and planted violations, to build a large skills
tree to time the CLI on. See [`../README.md`](../README.md).

These are not real skills for this repository. Agents and people must not
follow their instructions. They are not documentation for this repository,
and they are not published. Edit them only to change what the benchmark
measures.
